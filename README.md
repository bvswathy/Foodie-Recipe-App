# Foodie – Recipe App

## Run in Expo Snack
1. Visit https://snack.expo.dev/
2. Create a new Snack and replace `App.js` with this project's `App.js`.
3. Add `expo-image-picker` from Snack's Dependencies panel.
4. Preview and test on Snack or Expo Go.

## Features
- 10+ horizontal categories, including My Food
- Recipe detail view: ingredients, instructions, prep time, servings, calories, difficulty
- Search, favorite/unfavorite, Favorites section
- Add recipe with gallery image picker or image URL
- My Recipes, edit, delete and back navigation

Note: this starter keeps changes in app memory only; newly added recipes reset on a full app reload. Test the project before submission.
